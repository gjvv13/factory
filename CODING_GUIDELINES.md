# Coding guidelines

De coding guidelines zijn een **skill** geworden, zodat ze automatisch meekomen
zodra er code voor een applicatie geschreven wordt — niet alleen als je er zelf
naar verwijst.

De inhoud staat op één plek: [`skills/coding-guidelines/SKILL.md`](skills/coding-guidelines/SKILL.md).
Daar staat ook de definition of done, onder _Klaar_.

Elke applicatie krijgt de skill in `.claude/skills/coding-guidelines/` via
`factory sync`. Claude Code laadt hem dan zelf zodra de taak erom vraagt
(een commando, kanaal, route, migratie, client of test toevoegen of wijzigen).
Lezen kan gewoon: het is een markdown-bestand.
